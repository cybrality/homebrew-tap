# Homebrew tap

Homebrew formulae for software by Cybrality.

## PeerCloak

```bash
brew install cybrality/tap/peercloak
```

Then follow the printed instructions to register the background service and join
your network. Get a registration token from your dashboard at
https://app.peercloak.com.

Update with `brew upgrade peercloak`. The formula downloads release archives from
https://releases.peercloak.com and verifies their SHA-256 checksums.

More: https://peercloak.com
